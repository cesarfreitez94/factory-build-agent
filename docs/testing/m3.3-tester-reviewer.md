### 1. Verificar que los nuevos agentes existen

**Objetivo**: Confirmar que los archivos de definicion de agentes `tester_qa.md` y `revisor_codigo.md` existen y tienen contenido valido.

**Comando**:
```bash
python3 -c "
from pathlib import Path
import yaml

agents_dir = Path('templates/.opencode/agents')

for agent_name in ['tester_qa', 'revisor_codigo']:
    md_file = agents_dir / f'{agent_name}.md'
    assert md_file.is_file(), f'{agent_name}.md not found'
    text = md_file.read_text()
    parts = text.split('---', 2)
    assert len(parts) >= 3, f'Invalid frontmatter in {agent_name}.md'
    fm = yaml.safe_load(parts[1])
    assert fm['mode'] == 'subagent', f'{agent_name}.md mode is not subagent'
    assert len(parts[2].strip()) > 100, f'{agent_name}.md body too short'
    print(f'{agent_name}.md: OK')
"
```

**Resultado esperado**:
```
tester_qa.md: OK
revisor_codigo.md: OK
```

### 10. Verificar que `fba init` genera el state completo

**Objetivo**: Confirmar que el state.json generado por `fba init` incluye todas las fases y gates.

**Comando**:
```bash
python3 -c "
import json, subprocess, tempfile, os
from pathlib import Path

with tempfile.TemporaryDirectory() as tmp:
    from fba.cli import TEMPLATES_DIR
    # Use fba CLI to init
    cmd = ['python3', '-m', 'fba', 'init', '-d', tmp]
    subprocess.run(cmd, capture_output=True)
    
    state = json.loads(open(Path(tmp) / '.factory' / 'state.json').read())
    
    # Verificar fases
    expected_phases = ['init', 'elicitation', 'documentation', 'planning',
                       'tasks', 'construction', 'testing', 'review', 'ci_cd']
    for phase in expected_phases:
        assert phase in state['phases'], f'Phase {phase} missing'
    
    # Verificar gates
    expected_gates = ['elicitation', 'documentation', 'planning', 'tasks',
                      'schema', 'construction', 'testing', 'review']
    for gate in expected_gates:
        assert gate in state['gates'], f'Gate {gate} missing'
    
    # Verificar transitions
    assert 'testing' in state['valid_transitions']['construction']
    assert 'review' in state['valid_transitions']['testing']
    
    print('All phases and gates present: OK')
"
```

**Resultado esperado**:
```
All phases and gates present: OK
```
